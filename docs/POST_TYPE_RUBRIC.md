# Post-type rubric (draft — edit as you learn from real Yale Rugby posts)

Use this when you write classifier prompts and scoring rules.

## Scoreline / result graphic
- Clear jersey numbers or recognizable players
- Space for text overlay (sky, turf edge, or clean background region)
- Strong single focal point; not a messy pack
- Prefer horizontal or square-crop friendly frames

## Game day / hype
- Energy: tackle, break, lineout, celebration
- Faces and emotion help
- Crowd / kit / Yale branding is a bonus, not required

## Player spotlight
- One primary subject, sharp face or clear body language
- Minimal distraction behind them
- Works as a portrait crop

## Match action (feed / story)
- Ball in frame when possible
- Readable action (who is doing what)
- Avoid heavy motion blur unless it still reads as intentional

## Reject heuristics (cheap filters before the vision model)
- Extreme blur / out of focus
- Over/underexposed beyond recovery
- Near-duplicate of a higher-scoring frame
- Mostly backs, no ball, no readable action
